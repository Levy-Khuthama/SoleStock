# example-repo

A Python shoe inventory management program. It reads shoe data from `inventory.txt`, stores each item as a `Shoe` object, and lets the user view stock, search items by code, restock low-quantity shoes, calculate stock values, and identify the highest-quantity product.

## Files

- `inventory.py` - the main Python program.
- `inventory.txt` - the inventory data used by the program.

## How to run

```powershell
python inventory.py
```
